# Day 1 Lab Exercises

These hands-on labs follow the Day 1 demos. Each lab uses the same invoices and the same scoring as the demo before it, so you start every lab already knowing the scenario. In each lab you run the demo's stages yourself, in order. Every stage already works, and at four or fewer points you paste in one small piece of code that this guide gives you, and watch a measured number move.

To complete these exercises you need Python 3.10 or later and an Anthropic API key. Setup is in **DAY_0_SETUP_GUIDE.md**.

| Lab | Follows | Time | You write | Folder |
|---|---|---|---|---|
| Run a Model Tournament on Invoices | Demo 1A | 30 min | 23 lines | [LAB_1A_model_tournament](LAB_1A_model_tournament/README.md) |
| Evolve a Prompt and Measure Every Step | Demo 1B | 35 min | 12 lines | [LAB_1B_prompt_evolution](LAB_1B_prompt_evolution/README.md) |
| Catch Records That Are Valid but Wrong | Demo 1C | 35 min | 29 lines | [LAB_1C_structured_output_failure_lab](LAB_1C_structured_output_failure_lab/README.md) |
| Cut the Cost of a Policy Check Without Breaking It | Demo 1D | 40 min | 19 lines | [LAB_1D_cost_engineering](LAB_1D_cost_engineering/README.md) |

Optional extra for fast finishers: **Lab 1.5, Prompt Caching** in the **NEW_LABS** folder.

The older Day 1 labs (1.1 to 1.4: HR roster, IT incidents, warehouse receiving, purchase-order reconciliation) are kept in **_ARCHIVE_before_demo_alignment**. They are not part of the class.
